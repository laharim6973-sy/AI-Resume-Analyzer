🧮 Algorithms Used
All algorithms are implemented from scratch — no external ML libraries

TF-IDF (Term Frequency-Inverse Document Frequency)

Converts resume and job description text into numerical vectors by calculating how important each word is relative to the document. Used for keyword importance scoring and JD matching.

Cosine Similarity

Measures the similarity between the resume TF-IDF vector and the job description vector. A score of 1.0 means perfect match. Used to calculate the JD match percentage shown in results.

NLP — Natural Language Processing

Uses tokenization, stopword removal, and n-gram extraction to identify skills, action verbs, and key phrases. Regex-based named entity recognition for contact information extraction.

Flesch-Kincaid Readability Score

Calculates resume readability using the formula: 206.835 − 1.015 × (words/sentences) − 84.6 × (syllables/words). Higher score means easier to read and better for ATS systems.
